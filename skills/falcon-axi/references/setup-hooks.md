# setup hooks

setup hooks               install or repair all three session integrations

```text
npx -y @knowttl/falcon-axi setup hooks

Install or repair Claude Code, Codex, and OpenCode session integrations.
Requires a durable installation. No network calls or skill installation.

Examples:
  npx -y @knowttl/falcon-axi setup hooks
  npx -y @knowttl/falcon-axi setup hooks --help
```
