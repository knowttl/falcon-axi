# account show

account show <id>         the full detail for one account

```text
npx -y @knowttl/falcon-axi account show <account id>

The account id is the identifier printed by `npx -y @knowttl/falcon-axi account list`.

Example: npx -y @knowttl/falcon-axi account show abc123

This command is read-only and requires only Assets:read, which is license-gated to Falcon
Discover or Exposure Management.
```
