# quarantine show

quarantine show <id>      the full quarantined file record

```text
npx -y @knowttl/falcon-axi@next quarantine show <id>

Reads the full file metadata, including paths and associated alert/detection ids.
Requires Quarantined Files:read. No release, delete, or other action is performed.
Example: npx -y @knowttl/falcon-axi@next quarantine show synthetic-quarantine-01
```
