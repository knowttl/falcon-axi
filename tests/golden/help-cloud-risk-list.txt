falcon-axi cloud-risk list [--filter <FQL>] [--sort <field.direction>] [--limit N] [--cursor <token>]

list aggregated cloud risks.
--filter   raw FQL; + is AND, `,` is OR, values are single-quoted
--sort     upstream sort expression, for example cloud_provider.asc
--limit    rows in this call (default 20, ceiling 1000)
--cursor   opaque continuation token bound to the filter, sort, region and credential

Read-only; requires Cloud Security API Risks:read.
Risk detail is not offered: the official API has no risk-detail endpoint or risk-id filter.
Examples:
  falcon-axi cloud-risk list --filter "severity:'Critical'+status:'Open'"
  falcon-axi cloud-risk list --limit 100
